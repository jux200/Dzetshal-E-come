# Sprint 6.2.3 Order Stability

This patch preserves the Sprint 6.1 product image/gallery behavior and fixes checkout order submission.

## Fixed
- Defines transport fields for every checkout route.
- Pickup orders submit with empty transport details.
- Public transport orders require company, destination, receiver name, and receiver phone.
- Email and WhatsApp checkout use the same validated transport data.
- Prevents `ReferenceError: transportCompany is not defined` from stopping order creation.

## Browser console notes
Errors mentioning `runtime.lastError`, `extInfoFrame.js`, or `ERR_BLOCKED_BY_CLIENT` are commonly produced by browser extensions or ad blockers. They are not generated by the Dzetshal checkout code.

## Test
1. Place a Pickup at shop order.
2. Place a Public transport order and complete all transport fields.
3. Confirm both orders appear in Supabase and the admin Orders page.
