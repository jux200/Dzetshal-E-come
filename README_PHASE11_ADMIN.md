# Dzetshal Phase 11 Admin Dashboard

This version adds a professional admin interface:

- Secure Supabase Auth login
- Admin authorization via `admin_users`
- Dashboard KPIs
- Revenue trend chart
- Recent orders
- Best sellers
- Low stock alerts
- Orders management with status updates
- CSV exports
- Customer summaries
- Product manager UI with image tools
- Responsive mobile admin layout

Open: `admin/login.html` after deployment, or `/admin/login.html` on Vercel.
