# Dzetshal Practical Launch v1

This update adapts Dzetshal for the current boutique workflow:

- Cash on hand / cash on delivery
- MoMo Pay with manual verification
- Pay at shop by card or cash
- Pickup, public transport, or custom delivery
- Dispatch dashboard
- Store settings
- Homepage builder
- Theme customizer
- Activity logs
- System monitor
- Backup snapshot helper

Run `supabase/sprint6_practical_launch.sql` before testing the new admin pages.
