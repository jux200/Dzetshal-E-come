# Sprint 6.2 – Tracking and Brand Themes

This build is based directly on Sprint 6.1. The existing product image and gallery code in `index.html` was intentionally left unchanged.

## Setup
1. Run `supabase/sprint6_2_tracking_brand_theme.sql` in Supabase SQL Editor.
2. Deploy the complete folder, including `img/brand-logo-green.png` and `img/brand-logo-peach.png`.
3. Open `admin/theme.html` to select the logo theme and size.
4. Open `track-order.html` to test customer tracking.

Customer tracking requires the order number and the matching customer email or phone.
